How to add it to Outlook or Gmail

Outlook (desktop)

  1. Click Copy signature.
  2. File > Options > Mail > Signatures (new Outlook: Settings > Accounts > Signatures).
  3. New, name it, click in the editor and press Ctrl+V.
  4. Set it as default for new messages and replies, then Save.

Outlook on the web

  1. Settings > Account > Signatures, paste with Ctrl+V, Save.

Gmail

  1. Settings > See all settings > General > Signature.
  2. Create new, paste with Ctrl+V, then Save Changes at the bottom.
